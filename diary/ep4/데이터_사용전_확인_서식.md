# 데이터를 쓰기 전에 적어 두는 서식 (빈 양식)

에이전트 일기 4화에서 쓴 틀입니다. 자유롭게 복사해서 쓰세요.
이 서식은 생각을 정리하는 도구이며, 법적 준수 여부를 보증하지 않습니다. 실제 개인정보를 다룰 때는 소속 기관의 담당자 확인을 받으세요.

## 1. 처리 항목 표
| 항목 | 읽는가 (예/아니오) | 왜 필요한가 | 어디에 보관하는가 | 얼마나 보관하는가 |
|---|---|---|---|---|
| | | | | |
| | | | | |

- "읽지 않는 항목"도 표에 함께 적습니다. 읽지 않는다고 적어 두면 범위가 분명해집니다.

## 2. 흐름 (동의가 맨 앞)
1. 동의 확인: 동의가 없으면 다음 단계로 가지 않습니다.
2. 등록: 에이전트에는 이름 대신 가명 번호만 전달합니다.
3. 활동 제안: 사람이 확인한 뒤에만 반영합니다.

## 3. 기관에 확인할 질문 (예시, 상황에 맞게 고쳐 쓰세요)
1. 이 목적으로 이 항목을 처리해도 되는가
2. 동의서는 어떤 형식이 필요한가
3. 보관 기간과 파기 절차는 어떻게 하는가
4. 외부 서비스에 보낼 때의 기준은 무엇인가
5. 접근 권한은 누구에게 주는가
6. 사고가 났을 때 누구에게 알리는가
7. 동의를 철회하면 어떻게 처리하는가
8. 시험 단계에서는 가상 데이터만 써도 되는가

## 4. 답을 받기 전에
- 실제 데이터는 쓰지 않고 가상 데이터로만 시험합니다.
