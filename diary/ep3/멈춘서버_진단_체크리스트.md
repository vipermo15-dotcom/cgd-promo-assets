# 서버가 멈췄을 때 진단 체크리스트 (macOS 기준)

에이전트 일기 3화에서 쓴 순서입니다. "느린 것"과 "멈춘 것"을 먼저 가르는 것이 핵심입니다.
아래 명령은 읽기만 하며 아무것도 바꾸지 않습니다.

## 1. 계산 중인가, 기다리는 중인가
- 프로세스 확인: `ps -o pid,stat,etime,time,pcpu -p <PID>`
- CPU가 0%에 가깝고 누적 CPU 시간(TIME)이 거의 안 늘면 계산이 아니라 **무언가를 기다리는 중**입니다.

## 2. 무엇을 기다리는가
- 열고 있는 파일 확인: `lsof -p <PID> | tail`
- 마지막에 열려 있는 파일이 같은 곳에서 계속 멈춰 있는지 봅니다.

## 3. 그 파일이 내 컴퓨터에 있는가
- 파일 상태: `ls -lO <파일>`
- 플래그에 `dataless`가 보이면 파일 내용이 클라우드에만 있는 상태입니다. 읽는 순간 하나씩 내려받습니다.
- 작은 파일 하나를 읽는 데 오래 걸리는지 시간 제한을 걸어 재 봅니다: `perl -e 'alarm 20; exec @ARGV' cat <파일>`

## 4. 해결 시도 (순서대로)
1. 클라우드 동기화 폴더 밖에 같은 프로그램을 새로 설치합니다. 설정과 데이터 폴더는 복사합니다.
2. 새 위치에서 다시 켜서 응답 시간을 재 봅니다.
3. 개발 폴더 전체를 동기화 대상 밖으로 옮깁니다(근본 해결).

## 5. 기록
- 증상, 확인한 것, 원인, 해결, 걸린 시간을 한 줄씩 남깁니다.
- 원인을 모르는 구간은 "모름"이라고 적습니다.
