# 에이전트 5단계 점검표 (빈 양식)

에이전트 일기 1화에서 쓴 양식입니다. 자유롭게 복사해서 쓰세요.
점수는 스스로 매기는 예상치이며, 정답이 아니라 비어 있는 곳을 찾기 위한 도구입니다.

## 1. 단계와 점수 기준

각 단계를 0 / 0.5 / 1점으로 매깁니다.

| 단계 | 0점 | 0.5점 | 1점 |
|---|---|---|---|
| ① 규칙 (CLAUDE.md) | 없음 | 있으나 일부만 정함 | 하는 일·하지 않는 일이 모두 적혀 있음 |
| ② 스킬 | 없음 | 일부 반복 작업만 파일로 있음 | 반복 작업이 스킬 파일로 정리됨 |
| ③ 서브에이전트 | 없음 | 정의만 있고 안 써 봄 | 역할이 나뉘어 실제로 호출해 씀 |
| ④ 오케스트레이션 | 단계가 서로 안 이어짐 | 문서로만 흐름이 있음 | 실제로 이어서 돌아감 |
| ⑤ 검증·운영 | 시험 없음 | 시험은 했으나 실사용 전 | 시험 통과, 사람 승인 단계가 실제로 작동 |

## 2. 계산

점검 % = (①~⑤ 점수의 합) ÷ 5 × 100

## 3. 내 에이전트 기록

| 에이전트 이름 | ① | ② | ③ | ④ | ⑤ | 합 | 점검 % | 문서에 적힌 % |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |
| | | | | | | | | |

## 4. 읽는 법

- 문서 %는 "만들어 둔 것"을 세고, 점검 %는 "이어서 돌아가는 것"을 셉니다.
- 두 숫자의 차이가 클수록 보고서에는 보이지 않는 빈 곳이 있다는 뜻입니다.
- 가장 낮은 단계 하나만 골라 다음 주에 채우세요.
